# Stories

Put your own writing here. gedbook inserts each file into the book at the right place.

| File name | Where it appears |
| --- | --- |
| `introduction.md` | The "How to use this book" page |
| `branch-I5.md` | Opening of the branch whose ancestor has ID I5 |
| `I9.md` | The entry for the person with ID I9 |

IDs come from your GEDCOM. Look them up with `gedbook find your_tree.ged "Name"`, or read them from the `media_matches.csv` sheet.

Supported formatting: blank lines between paragraphs, `**bold**`, `*italic*`, `## heading`, `- list items`, and `> quoted text` for interview excerpts.

See `examples/stories/` for samples. Everything in this folder except this README is ignored by git so your family's writing stays private.
