# Fonts

The book is set in Lora (body) and Carlito (labels). Both are free under the SIL Open Font License.

Download the .ttf files and place them in this folder:

- Lora: https://fonts.google.com/specimen/Lora
- Carlito: https://fonts.google.com/specimen/Carlito

gedbook embeds every .ttf or .otf file it finds here. With no fonts here, the PDF falls back to Georgia or DejaVu Serif. Font files are ignored by git; each user downloads their own.
