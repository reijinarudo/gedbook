# Research session protocol

A template for research sessions with an AI assistant. Edit the paths and habits to fit your own work.

## 1. Start of session

1. Read this protocol.
2. Read the status note for the branch being researched (for example `notes/<branch>_status.md`). If none exists, create one from the template at the end.
3. Confirm the focus person and the research question in one line, then start. One person per session.

## 2. Searching

- Search your own media folder before searching online. Many records are already there under older file names. Try surname spelling variants.
- When the focus person is hard to find, search for the household: spouse, children, siblings, parents.
- Prefer free sources with clear reuse terms (FamilySearch, national archives, state archives) for anything that may appear in the book.

## 3. Evidence standards

- A match needs three independent anchors drawn from name, age, place, relatives, occupation, and race or color as recorded. A name alone never counts.
- Record the informant on every death certificate and weigh the record by who that person was. Close family ranks above in-laws, and both rank above a hospital clerk or a stranger.
- Tag every finding: DOCUMENTED, FAMILY REPORT, INFERRED, or UNDER REVIEW.
- Note every conflict between records. Say which reading is better supported and why. Never resolve a conflict silently.
- Write that records support or indicate a conclusion, and keep the word "prove" out of findings.

## 4. File rules

- Copy downloads into your media folder; never move or delete the originals.
- Name copies `<year>_<recordtype>_<given>_<surname>.<ext>`, for example `1920_census_samuel_hollis.pdf`. gedbook matches image files (JPG, PNG, TIFF, GIF, WebP, BMP) to people by these names.
- Check for duplicates before copying.
- Never edit shared online trees on the user's behalf. Propose changes in chat.
- Never print subscription-site record images in the book. Transcribe them.

## 5. End of session

1. Add new records, findings, and leads to your record index (a spreadsheet works).
2. Append a dated section to the branch status note: findings, file names, record URLs, next leads.
3. Report two to four findings and one next step.

## 6. Sensitive findings

Adoption, institutionalization, illegitimacy, race and passing, enslavement, and violent deaths are reported as evidence. The family decides how they appear in the book. If a relative has asked that their line not be researched, respect that.

## Branch status note template

```
# <Branch> Research Status
## Focus person and question
## What is already known (with sources and evidence tags)
## Records on file
## Conflicts
## Leads (ranked)
## Session log
```
